Mario Kart Betting

GitHub Repository

Project Evolution

What began as a simple horse betting project transformed into a fully-realized racing game with a unique twist. Inspired by the classic SNES Mario Kart aesthetic, the game combines betting mechanics with a custom-built .NET game framework.

Technical Innovations

  • Custom Sprite Sheet Management System
  • Advanced Sound Management Framework
  • Proprietary Betting Mechanics Engine
  • Top-down SNES-style Rendering Technique

Custom Game Systems

To overcome .NET limitations and create a robust game experience, I implemented several custom systems from scratch:

  • Sprite Sheet Manager: Efficiently handles sprite animations and rendering
  • Sound Manager: Provides advanced audio control and playback
  • Betting Mechanics: Developed a complex betting and race prediction system
  • Rendering Engine: Created a custom top-down rendering approach mimicking SNES-era graphics

Game Mechanics

Blend unique betting strategies with racing simulation. Players can:

  • Place bets on race outcomes
  • Analyze racer statistics
  • Experience nostalgic SNES-style top-down racing
  • Manage in-game economy and betting resources

Development Challenges

Building a complete game system in .NET presented unique challenges:

  • Creating performant sprite and sound management
  • Implementing custom rendering techniques
  • Developing complex betting prediction algorithms
  • Maintaining SNES-era graphical aesthetic
