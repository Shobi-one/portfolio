GOODNIGHT

A 2D Unity Game

Project Overview

Play on Itch.io

Goodnight is a 2D narrative exploration game developed in Unity, demonstrating skills in C# programming, game design, and environmental storytelling. The project showcases my ability to create immersive experiences through atmospheric design and intuitive gameplay mechanics.

Core Development

  • Scene Management & Transitions

Game Design

Development Process

Planning & Design
Concept Development

Analyzed inspiration from games like Yume Nikki and Undertale to create a unique narrative exploration experience. Designed core gameplay mechanics and atmospheric elements.

Implementation
Unity Development

Built the game using Unity and C#, implementing smooth 2D movement, atmospheric effects, and intuitive puzzle mechanics. Focused on creating an immersive player experience.

Polish & Release
Final Optimization

Refined gameplay mechanics, optimized performance, and prepared the game for release on Itch.io. Implemented final audio design and visual polish.

Key Features & Skills Demonstrated

Game Programming

Implemented complex game logic using C# including player movement, collision detection, and interactive elements.

Environmental Design

Created atmospheric environments that tell a story through visual design and player exploration.

User Experience

Designed intuitive controls and gameplay mechanics that encourage exploration and emotional engagement.

Project Management

Successfully planned, developed, and released a complete game project from concept to publication.
