CLIPENGINE

A Browser-Based Game Engine

Project Overview

View on GitHub

ClipEngine is a browser-based game engine and visual editor for creating 2D and 3D interactive experiences. Built with modern web technologies, it provides an intuitive IDE-like interface with integrated audio support, live preview, and real-time code editing. The engine combines the power of p5.js for 2D graphics, Three.js for 3D rendering, and Tone.js for comprehensive audio capabilities.

JavaScript p5.js Three.js Tone.js Vite Web Workers

Key Features

🎨 2D Game Development

Create 2D games and animations using p5.js with an intuitive sprite-based system. Features include real-time animation, collision detection, and dynamic behaviors.

🎮 3D Scene Editor

Build 3D environments with Three.js including primitives, custom models, and advanced lighting. Import GLTF/GLB models and edit properties in real-time.

🎵 Integrated Audio Engine

Comprehensive audio system powered by Tone.js with sound generation, synthesis, effects processing (reverb, delay, distortion), and mixing capabilities.

💻 Visual Code Editor

Built-in code editor for writing object behaviors with syntax highlighting. Edit sprite logic, 3D animations, and custom interactions on the fly.

📦 Scene Management

Save and load complete scenes using JSON-based configuration. Includes sample scenes for both 2D and 3D to get started quickly.

⚡ Live Preview

See your changes in real-time with the built-in viewport. Switch between 2D and 3D modes seamlessly with immediate feedback.

🔧 Web Workers

Multi-threaded processing support for performance-intensive calculations without blocking the main thread or game logic.

📱 PWA Support

Installable as a Progressive Web App with offline capability. Works across all modern browsers with WebGL support.
